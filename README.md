## 0.3 수정 내용

- 도로 조회가 실패해도 먼저 받아온 지형을 표시하고 유지합니다. 필지 조회 실패도 지형·도로를 지우지 않습니다.
- 504/502/503/408 또는 연결·시간 초과에는 30초 후 한 번 자동 재시도합니다. 도로 요청의 서버 처리 제한은 60초, 클라이언트 제한은 90초입니다. 자동 재시도까지 포함하면 약 3분 30초 걸릴 수 있으며 닫기로 취소할 수 있습니다.
- **도로만 다시 불러오기** 버튼은 기존 지형·필지를 유지한 채 도로만 조회합니다. 도로 옵션을 꺼도 지형은 유지됩니다.
- 선택한 자료 중 준비되지 않은 항목이 있으면 배치 직전에 제외 여부를 확인합니다.
- 반복 504 오류 후 지형·배치 버튼 유지, 도로 재시도 성공, 표고 중복 조회 방지를 WPF 화면 검사로 확인했습니다. 재시도 정책 7개와 기존 검사 35개도 통과했습니다.
- 2026-10-06 실제 서버에서 국립중앙의료원 주변 도로 90개 조회 성공. 서버 상황에 따라 실패 가능성은 남습니다. Revit 내부의 실제 요소 생성은 아직 검증하지 않았습니다.

**업데이트:** Revit을 종료한 뒤 새 폴더의 `Install.cmd`를 실행하세요. 이전 폴더의 파일을 덮어쓸 필요가 없습니다. 새 창 제목 끝의 **0.3**으로 버전을 확인할 수 있습니다.

국내 주소 주변의 지형, 개략 도로 면, 선택한 필지의 합친 경계를 만드는 시제품입니다. 현재 실행 파일은 **Revit 2026용**입니다.

## 먼저 사용하는 방법

1. Revit을 종료하고 압축 푼 폴더에서 `Install.cmd`를 실행합니다. 이전 0.1 등록은 백업 후 새 경로로 바뀝니다.
2. Revit 2026의 **애드인 → 외부 도구 → 한국 지형 생성**을 엽니다.
3. **국립중앙의료원 예시 위치 → 지형·도로·필지 불러오기**를 누르면 키 없이 지형과 도로를 불러옵니다.
4. 대지 경계도 필요하면 **대지 경계 가져오기**를 체크하고 펼쳐진 설정에 **브이월드 인증키와 발급 시 등록한 URL**을 입력한 뒤 다시 불러옵니다.
5. 주소 위치가 들어 있는 필지 1개를 자동 선택합니다. 미리보기의 필지 면이나 오른쪽 목록을 클릭해 주변 필지를 추가·해제합니다.
6. 왼쪽 아래로 스크롤해 **레빗에 배치**를 누르고 평면도에서 중심점을 클릭합니다.

인증키는 채팅에 보내지 말고 플러그인 안에서 입력하세요. 브이월드 키가 없으면 도로까지 사용할 수 있으며, 필지 경계는 임의로 만들어주지 않습니다. [브이월드 개발자 안내](https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do)

## 확인한 내용

- 설치된 Revit 2026 API로 빌드 성공. 빌드 경고 3개, 오류 0개이며 레빗 실행 시 확인이 필요합니다.
- 국립중앙의료원 공식 홈페이지 지도 좌표 주변 500×500m 표고 조회 성공.
- 17×17, 총 289점. 실제 조회 간격 31.25m. 조회된 자료 표고 23~81m.
- 좌표 방향, 누락 표고, 필지 자동 선택·합치기·구멍 보존, 도로 폭·범위 처리 등 35개 검사 통과.
- 국립중앙의료원 주변 도로 90개 조회. 교량·터널 등의 3개 도형 제외. 조회된 90개 도로는 모두 폭 정보가 없어 임시 폭 6m를 사용했습니다.
- 실제 도로 자료로 범위 자르기와 삼각형 면 2,782개의 면적 보존 검사 통과.
- WPF 화면 생성, 예시 선택, 도로 미리보기, 시험용 필지 선택·해제, 위치·범위 변경 시 이전 자료 무효화 검사 통과.

**아직 확인하지 못한 내용:** Revit 내부에서 실제 지형·도로·경계 생성 및 높이 배치, 카카오 인증키를 사용한 주소 검색, 브이월드 인증키를 사용한 실제 필지 조회, 측량값 비교, Revit 2025 빌드·실행. 필지 처리는 공식 API 규격과 시험용 응답·도형으로 검사했습니다. 따라서 측량 정확도나 두 버전의 동작을 검증한 완성품은 아닙니다.

## 설치와 실행

1. 이 폴더를 유지할 위치에 놓고 Revit을 종료합니다.
2. `Install.cmd`를 실행합니다. 현재 사용자 Revit 2026 Addins 폴더에 등록 파일 하나를 만듭니다. 같은 시제품의 기존 등록 파일은 백업 후 갱신하고, 다른 플러그인과 충돌하면 중단합니다. 시스템 실행 정책은 변경하지 않습니다. `NetTopologySuite.dll`을 포함해 폴더 전체를 유지하세요.
3. Revit 2026에서 지형 솔리드 유형이 포함된 프로젝트를 열고, 작업 기준면이 있는 평면 뷰로 이동합니다.
4. **애드인 → 외부 도구 → 한국 지형 생성**을 실행합니다. 서명되지 않은 개인 시제품이므로 Revit이 로드 여부를 물을 수 있습니다.
5. **국립중앙의료원 예시 위치 → 지형·도로·필지 불러오기**로 인증키 없이 지형과 도로를 먼저 확인할 수 있습니다. 필지는 별도 인증키가 필요합니다.
6. 범위·표고 미리보기·레벨·지형 유형·기준 표고를 확인한 뒤 **레빗에 배치**를 누릅니다.
7. 평면 뷰에서 지형 중심점을 선택합니다. ESC로 취소할 수 있습니다.

등록 파일은 DLL의 현재 경로를 가리킵니다. 등록 후 이 폴더를 이동하면 경로를 다시 등록해야 합니다. 제거하려면 Revit을 닫고 사용자 Addins/2026 폴더의 `KoreaTerrain.addin`만 제거합니다.

## 일반 주소 검색

카카오디벨로퍼스에서 발급한 REST API 키를 실행 창의 비밀번호 입력란에 입력합니다. 키는 파일에 저장하거나 로그로 남기지 않습니다. 키를 채팅에 보낼 필요는 없습니다.

도로명·지번 주소를 입력해 검색하고 결과를 직접 선택합니다. 이 버전은 장소명 검색 API를 사용하지 않으므로 '국립중앙의료원' 대신 **서울 중구 을지로 245**를 입력합니다. 예시 버튼은 공식 홈페이지의 고정 지도 좌표를 사용하며, 주소 검색 API 결과를 가장하지 않습니다.

검색 주소는 카카오에, 표고 조회 좌표는 Open Topo Data에 전송됩니다. 도로 범위는 Overpass에, 필지 조회 범위와 인증키·등록 URL은 브이월드에 전송됩니다. 키는 파일에 저장하지 않습니다. 지도 확인 버튼은 외부 브라우저에서 OpenStreetMap을 엽니다.

## 도로와 대지 경계

- **도로:** OpenStreetMap의 차량 도로 중심선을 폭만큼 넓힌 개략 면입니다. 일반 모델(DirectShape)로 만들며 실제 도로 경계, 도로 바닥·연석·보도 객체는 아닙니다. 폭이 없거나 해석할 수 없는 구간은 입력한 임시 폭(기본 6m)을 사용합니다. 교차로에서 서로 다른 도로 면이 겹칠 수 있습니다. 교량·터널·비지상 레이어와 보행 전용 길은 포함하지 않습니다.
- **높이:** 도로 면과 경계선은 표고 격자를 보간한 높이에 표시용 0.15m를 더합니다. Revit 지형의 삼각분할과 보간 방식이 달라 부분적으로 지형과 겹치거나 뜰 수 있습니다. 실제 도로 경사·횡단면을 재현하지 않습니다.
- **필지:** 브이월드 연속지적도 `LP_PA_CBND_BUBUN`을 조회합니다. 필지 도형을 합쳐 내부의 공통 경계를 제거하고 바깥 경계와 구멍 경계를 참고용 모델선으로 만듭니다. Revit의 전용 대지경계(PropertyLine) 객체가 아닙니다. 떨어진 필지는 억지로 연결하지 않습니다.
- **자동 선택:** 주소 위치가 한 필지 안에 있을 때만 선택합니다. 주소 좌표가 공통 경계에 있거나 건물 대표점이 실제 대지와 어긋나면 직접 선택해야 합니다. 병원 전체 대지를 주소만으로 확정하지 않습니다.
- **범위:** 필지 조회를 켜면 최대 1,400m입니다. 선택 필지가 범위 밖까지 이어지면 범위 안의 실제 경계 구간만 생성합니다. 자른 사각형 테두리를 대지 경계로 만들지 않습니다. 전체 경계가 필요하면 조회 범위를 늘려야 합니다.
- **자료 오류:** 실패한 조회의 불완전한 데이터는 사용하지 않습니다. 성공한 지형·도로·필지는 유지하며, 준비되지 않은 항목을 제외하고 배치할지는 배치 직전에 확인합니다.
- **되돌리기:** 지형·도로·경계를 하나의 트랜잭션으로 생성합니다. 반복 생성 시 기존 결과를 자동 교체하지 않으므로 이전 결과를 되돌린 뒤 재생성하세요.

연속지적도는 측량자료로 사용하지 못하는 참고용 도면입니다. [공공데이터포털 자료 설명](https://www.data.go.kr/data/15123899/openapi.do)

## 높이와 위치

- 예시 중심: 위도 37.567271983583716, 경도 127.00579256203822. 병원 공식 '오시는길' 지도 좌표입니다. 측량점은 아닙니다.
- 범위: 중심 기준 정사각형 120~2,000m. 경계에 점을 포함하므로 요청 간격과 실제 간격은 다를 수 있습니다.
- 모델 X는 동쪽, Y는 북쪽으로 가정합니다. 프로젝트 진북 회전, 한국 평면좌표계, 공유좌표 자동 설정은 아직 구현하지 않았습니다.
- 평면 위치는 사용자가 지정한 배치점에 맞춥니다. 선택점의 Z는 사용하지 않습니다.
- 자료 표고에서 지정한 기준 표고를 빼고 선택한 레벨 높이를 더합니다. 기본 기준 표고는 조회 범위의 최솟값입니다. 예를 들어 자료 표고 23m를 레벨 0m에 맞추면 자료 표고 40m인 점은 레벨보다 17m 위에 배치됩니다.
- WGS84의 국소 거리 근사식을 사용합니다. 지적 경계 정합용 투영 변환이 아니며 2km 이내의 초기 검토만 대상으로 합니다.
- 생성된 지형의 설명 매개변수에 자료 출처, 조회 시각, 위치, 기준 표고를 기록합니다.

## 자료와 한계

현재 자료는 **SRTM GL1 v3, 약 30m급**이며 Open Topo Data의 공개 시험 API를 사용합니다. SRTM은 2000년 관측 기반으로 현재의 대지 상태를 보장하지 않으며 건물·수목 영향을 포함할 수 있습니다. EGM96 기준 표고를 사용하므로 국내 측량 높이 기준과 동일하다고 가정하면 안 됩니다. 더 촘촘한 보간은 원자료의 정확도를 높이지 않습니다.

국립중앙의료원 주변에서 조회된 23~81m는 원자료 값의 범위입니다. 실제 지면이 그만큼 오르내린다는 검증 결과가 아닙니다. 정밀 대지 검토에는 국내 지형도·측량 자료와 대조해야 합니다.

공개 API는 요청당 최대 100점, 초당 1회, 하루 1,000회 제한이 있습니다. 이 시제품은 한 프로세스에서 요청을 1.1초 이상 간격으로 나누지만 여러 Revit 프로세스의 합산 사용량을 관리하지 않습니다. 오류·누락 표고가 있으면 생성하지 않고 중단합니다. 상용 배포 단계에서는 자료 이용 조건, 서버 운영, 캐시와 사용량 관리를 별도로 정해야 합니다.

국토지리정보원의 고해상도 표고 자료를 전국 단위로 자동 조회할 수 있는 경로와 배포 조건은 **아직 확정하지 않았습니다**. 현재는 그 자료를 사용하지 않습니다. 건물 자동 생성, 실제 도로 경계 취득, 지도 위 범위 드래그도 미구현입니다.

도로 조회는 공개 Overpass 서버를 사용하는 개인 시험용입니다. 10분 메모리 캐시와 프로세스 내 30초 요청 간격을 적용했습니다. 여러 사용자를 대상으로 배포하거나 상업용으로 운영할 때는 별도 서버·제공자를 마련해야 합니다. 도로 데이터의 출처 표시는 `© OpenStreetMap contributors`, 라이선스는 ODbL입니다. [출처와 라이선스](https://www.openstreetmap.org/copyright), [공개 서버 사용 안내](https://wiki.openstreetmap.org/wiki/Overpass_API)

## 개발

.NET 8 SDK 및 대상 Revit API DLL이 필요합니다. `build.ps1 -Version 2026`으로 빌드합니다. 2025용 빌드 설정도 있지만, 이 PC에 Revit 2025 API가 없어 해당 빌드를 제공하지 않습니다. 2026 DLL을 2025용이라고 바꾸어 배포하지 마세요.

검사: `dotnet run --project tests/Checks.csproj`

실조회: `dotnet run --project tests/Checks.csproj -- --live sample`

다음 검증은 새 Revit 프로젝트에서 생성 취소·실행, 레벨 0과 비영 레벨의 높이, 도로 면과 지형 겹침, 경계 모델선 표시, 저장 후 재열기 순서로 진행합니다. 이어서 인증키를 사용한 주소·필지 검색과 국내 측량 자료 비교를 진행합니다.
